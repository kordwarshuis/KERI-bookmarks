Arranging bookmarks

Turn on Edit layout in the footer to reveal drag handles and edit controls. Renames, deletes, and new items are kept in this browser’s localStorage until you copy the HTML into the file.

Edit layout
Shows or hides the per-card and per-section handles, pencils, and delete buttons.
Add bookmark
Creates a card in the section you pick. It stays in this browser only until you copy the HTML.
Add section
Creates a new section (and nav link). Same as bookmarks: browser-only until you copy the HTML.
Copy HTML
Puts the current page — including your order and additions — on the clipboard. Paste it over index.html and deploy when everyone should see this layout.
Reset layout
Forgets this browser’s saved arrangement and reloads the page as written in the file. The file itself is not changed.

Section pencil renames; the cross deletes a section and the bookmarks inside it. Those changes also live in localStorage until you copy the HTML.
